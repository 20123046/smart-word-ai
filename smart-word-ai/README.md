# SmartWord AI - 次世代文書作成・ブラッシュアップ支援SaaS

社内の文書作成における「過去バージョンの紛失」「推敲の無駄な時間」を解消するプライベートクラウドソリューションです。

## 特徴
- **AIアシスタント機能**: 自然言語指示による文章ブラッシュアップ
- **自動バージョン履歴**: 過去の文章（Ver.1, Ver.2）をリアルタイムに比較・復元
- **Word (.docx) 即時出力**: クライアント側でそのまま使えるWord形式ダウンロード
- **コンテナ化対応**: Docker Compose により即座に自社環境へデプロイ可能

## 起動方法 (Docker)

docker-compose up -d --build
